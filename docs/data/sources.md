# KROMA Data Catalogue

Status on 18 September 2026 years. `Получено` means a local file excluded from Git; The rest of the lines describe the proven path of access, not integration. Sources, versions, exact AOI and SHA-256 are stored in manifest. Data for the whole of Russia is uploaded in spatial and temporal parts, and heavy rasters are only for the selected region or incident.

| [NASA FIRMS Gas Flares](https://firms.modaps.eosdis.nasa.gov/descriptions/Gas_Flares.html) — hard-negative candidates | FIRMS layer based on World Bank/NOAA, check individual source conditions before downloading | Global torch points from inventory 2012–2023; coordinates, year, size/volume. | Not loaded; the temporal activity of the torch and the image must coincide. Proximity to the torch is a weak mark, not proof of false fire. |
| [GWIS burned area](https://gwis.jrc.ec.europa.eu/apps/country.profile/downloads) — spot-marking | Download shapefile from JRC; reuse conditions check on a specific set | Globally; derived from MODIS MCD64A1, rough hare contours and annual/seasonal figures. | Not loaded. Missing small fires, lag and mismatch with active detections; **ground truth** incident-level confidence. |

Official [ISDM-Rosleskhoz / Avialesoprotection](https://public.nffc.aviales.ru/main_pages/) It is important for accident matching, but an open reproducible API with verified incident labels has not yet been confirmed. Full interface requires login; legal unloading regime check prior to use.

To update the boundaries are considered [regular OSM extracts by Geofabrik](https://download.geofabrik.de/russia.html) (Fresh but multi-gigabyte and ODbL), [OpenData.Earth](https://open-data.earth/data/administrative-boundaries) (version 2026, CC BY, but need access request and verification of the original Russian polygons) and official [Okata Rosstat](https://www.rosstat.gov.ru/opendata/7708234640-okato) (codes/names, without geometry). For compliance with the subject → Federal district is [rosstat](https://www.rosstat.gov.ru/storage/mediabank/met_519-22092025.pdf); The machine-verified table has not yet been collected. Any replacement layer must be matched to identifiers and licenses before the statistics are published.

## Existing local data

`research/experiments/build_evaluation_cohort.py` checks for SHA-256 NASA CSV and calls **existing** `backend/app/services/firms.py` normalizer. `data/raw/firms/sample_viirs_snpp_071223.csv` and `data/interim/sample_viirs_snpp_071223.jsonl` are locally located outside Git. [Manifest sampling](../../research/experiments/viirs-pilot-manifest.json) 200 candidates without reference labels. One day S-NPP fails to evaluate Thermal Memory, Seasonality, False-Positive Reduction or National Quality.
